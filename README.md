# Hello React Site

A Vite + React starter with a Hello World homepage.

## Local Development

This workspace includes a local Node.js/npm install one directory above the repo.

```bash
../tools/node-v24.14.0-darwin-arm64/bin/npm install
../tools/node-v24.14.0-darwin-arm64/bin/node node_modules/vite/bin/vite.js dev
```

## Build

```bash
../tools/node-v24.14.0-darwin-arm64/bin/node node_modules/vite/bin/vite.js build
```
